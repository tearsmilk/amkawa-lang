# NaoVisual

Клиентский мод визуалов для Minecraft **1.21.11** (Fabric, Java 21, Mojang mappings). Написан с нуля на Java,
пакет `milk.naovisual`, автор tearsmilk. Меню открывается на **правый Shift** (клавиша меняется в настройках управления),
редактор HUD — на правый Ctrl (модуль «Клавиши»).

## Модули

| Категория | Модули |
|---|---|
| **HUD** | Водяной знак, Броня, Боссбары, Расходники, Перезарядки, Прицел, Хотбар, Клавиши, Иконки, Инвентарь, Инфо о предметах, Список модулей, Без огня, Уведомления, Игрок, Эффекты, Скорборд, Таб, Цель, Тотемы |
| **Визуалы** | Подсветка блока, Шляпа, Друзья, Эффект рук, Хитбоксы, Круги прыжка, Подсветка цели, Шлейфы |
| **Частицы** | Атмосфера, Пузыри удара, Частицы удара, Частицы тотема |
| **Мир** | Яркость, Туман, Навигатор, Свет, Время |
| **Прочее** | Соотношение сторон, Кристаллы, Руки, Звук удара, Эффект убийства, Защита ника, Талисман |
| **Клиент** | Фейк-игрок, Клавиши, Язык, Тема, Discord |

HUD-модули перетаскиваются в редакторе (прилипание к центру и краям, колесо — масштаб, ПКМ — настройки).
Прицел, хотбар, эффекты, боссбары, скорборд и таб заменяют ванильные элементы, пока включены.

## Настройки и профили

Типы настроек: переключатель, число (ползунок), цвет (пикер HSV + альфа, режимы «свой / радуга / тема»), выбор, мульти-выбор,
клавиша, текст, группа (сворачивается, вложенные настройки, `visibleWhen`). Конфиг — JSON в `config/naovisual/`:
`client.json` (активный профиль, друзья) и `profiles/<имя>.json`. Профили создаются, загружаются и удаляются из меню.

Темы: «Клод» (слоновая кость / уголь / терракота `#D97757`, по умолчанию), «Ночь», «Молоко», «Сакура», «Океан» — плюс свой акцент.
За меню — размытие и затемнение (модуль «Тема»). Discord Rich Presence реализован своим IPC-клиентом без библиотек.

Серверные части исходного мода (API, рейтинги, календарь активности) намеренно не реализованы.

## Сборка

```bash
cd naovisual
./gradlew build --no-daemon
# build/libs/naovisual-<версия>.jar + naovisual-mod.json (метаданные для лаунчера Эта)
```

Тесты — JUnit 5 (`./gradlew test`). CI: `.github/workflows/naovisual-mod.yml` собирает на каждый push в `naovisual/**`,
релиз — тег `naovisual-v<версия>` или `workflow_dispatch` с `release_version`.

## Структура

- `core/setting` — типы настроек, `core/module` — `Module`, `HudModule`, реестр и рассылка событий;
- `core/render` — 2D/3D примитивы (скруглённые панели, линии, боксы, кольца, билборды), проекция в экран;
- `core/particle` — своя система частиц, `core/discord` — IPC-клиент, `core/config` — профили;
- `menu/` — меню (рисуется в сетке 966×699 и масштабируется под экран), `core/hud/HudEditorScreen` — редактор HUD;
- `mixin/` — точечные миксины: огонь на экране, руки, взмах, тотем/урон/прыжок, кристаллы, туман, гамма, время суток, чат, аспект.
