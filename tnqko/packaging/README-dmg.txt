TnQkoWallpaper — живые обои из видео для macOS 11+ (Intel)

1. Перетащи TnQkoWallpaper.app в «Программы».
2. Первый запуск: правый клик по программе → «Открыть» → «Открыть»
   (программа не подписана сертификатом Apple, поэтому macOS спрашивает).
3. Перетащи видео (.mp4 / .mov / .m4v) в окно и нажми на карточку — оно станет обоями.

Программа живёт в строке меню (значок ▶ справа сверху): пауза, звук, библиотека, выход.
Звук, масштаб, экраны, пауза от батареи и автозапуск — в правой панели окна.
WebM / MKV macOS не проигрывает: перекодируй в .mp4 (H.264 / HEVC), например в HandBrake.
