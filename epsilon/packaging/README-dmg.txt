Epsilon — заметки, файлы и ссылки локально (macOS 11+, Intel)

УСТАНОВКА
1. Перетащите «Epsilon» в «Программы».
2. Первый запуск: правый клик → «Открыть» → «Открыть» (приложение не подписано сертификатом Apple).
   Если не открывается: Терминал → xattr -cr "/Applications/Epsilon.app"

ГДЕ ДАННЫЕ
- Хранилище по умолчанию: ~/Documents/Epsilon — обычная папка с .md файлами.
  Её можно открыть в Obsidian, VS Code, любом редакторе; можно синхронизировать любым способом.
- Файлы и картинки — в подпапке attachments, закладки — в .epsilon/links.json,
  удалённое — в .trash. Ничего не отправляется в интернет.
- Другое хранилище: кнопка с названием хранилища внизу слева.
- Настройки (⚙ внизу слева или ⌘,): тема, шрифт, хранилище и Корзина — восстановить удалённое
  или «Очистить корзину»: всё удалённое переместится в Корзину macOS (там работает «Вернуть»).
  Можно включить «Удалять сразу в Корзину macOS».

ГОРЯЧИЕ КЛАВИШИ
⌘N новая заметка · ⌘O быстрый переход · ⇧⌘F поиск · ⌘E редактор/разделить/просмотр
⇧⌘A прикрепить файлы
⌘\ правая панель · ⌘B жирный · ⌘I курсив · ⌘K ссылка · ⌘+/⌘− размер шрифта
/ в начале строки — меню блоков (заголовки, задачи, код, таблица, выноска…)

КАЛЕНДАРЬ И ЗАДАЧИ (▦ Календарь слева, ⇧⌘C)
- Задача — любая строка «- [ ] …» в заметке. Дата: 📅 2026-10-20, время: ⏰ 14:30,
  приоритет: ⏫ высокий / 🔼 средний / 🔽 низкий. Задачи в дневнике дня относятся к этому дню.
- Месяц с количеством задач по дням; справа — план выбранного дня: добавить (с временем
  и приоритетом), отметить, перенести (сегодня / завтра / через неделю / на дату), удалить.
- Планировщик: просрочено, сегодня, ближайшие 7 дней, без даты.
- Напоминание macOS в назначенное время (пока Epsilon открыт).
- Двойной щелчок по дню — дневник этого дня; по задаче — заметка с этой строкой.

ВЛОЖЕНИЯ: ФАЙЛЫ, ФОТО, ВИДЕО, GIF (📎 в заголовке заметки, ⇧⌘A)
- Прикрепить: кнопка 📎, «/» → «Вложение…», перетащить файлы в заметку или вставить картинку ⌘V.
  Файлы копируются в attachments хранилища, в заметку добавляется ссылка.
- В просмотре: фото и GIF (анимированные) — прямо в тексте; видео, аудио, PDF и другие файлы —
  карточкой с превью, типом и размером.
- Щелчок по вложению — просмотрщик: фото с масштабом (⌘+колесо), видео и аудио с плеером
  (пробел — пауза), ←/→ — соседние вложения заметки, «Открыть в программе», «Показать в Finder».
- Раздел «Файлы» — все вложения с превью и фильтром: фото, GIF, видео, аудио, документы.

ВОЗМОЖНОСТИ
- Markdown с просмотром, [[вики-ссылки]], обратные ссылки, оглавление, #теги, граф связей
- Задачи - [ ] (щелчок в просмотре отмечает), выноски > [!note], таблицы
- Вставка кода: язык определяется автоматически, блок с подсветкой и кнопкой «Копировать»
- Перетаскивание файлов и вставка картинок (⌘V) — копируются в attachments
- Раздел «Ссылки» — закладки с тегами, «Файлы» — все вложения, «Сегодня» — дневник
- Экспорт заметки в PDF, светлая/тёмная тема
