# Figma: Тета — UI

Файл «Тета — UI» в команде **Lotus** (создаётся при первом запуске скриптов через `use_figma`).

> **Правило:** UI-кит и *все* экраны Теты живут в Figma. Любой новый экран, диалог или компонент добавляется
> в эти скрипты в том же изменении, что и код, и выкладывается в Figma.

1. `01_ui_kit.js` — страница **UI Kit**: токены (коллекции «Theta — Light» / «Theta — Dark», зеркало `theta/theme.py`),
   иконка θ, компоненты: Play button, Hero (карта / режим / источник / опции), Mini card (задание дня), Record row,
   Overlay (верхняя панель раунда), Map panel (карта ответа с кнопками размера и булавкой), Result panel, Toast, Attribution.
2. `02_screens.js` — страница **Screens**:

| Экран | Темы | В приложении |
|---|---|---|
| Загрузка — логотип θ, прогресс | Light | при запуске |
| Главная — приветствие, карточка новой игры (карта, режим, источник, время, опции, «Играть»), задание дня, недавние игры | Light, Dark | «Главная» |
| Игра — панорама во весь экран, верхняя панель (раунд, очки, таймер), кнопки движения, подпись автора, карта ответа в углу (свёрнута / развёрнута / закреплена) | Light | «Играть» |
| Игра — результат раунда: расстояние, очки, линия между меткой и местом, «Следующий раунд» | Light | после «Ответить» |
| Игра — страны подряд: выпадающий список стран вместо карты, счётчик серии | Light | режим «Страны подряд» |
| Итоги — сумма, раунды, «Играть ещё» / «На главную» | Light | после 5 раундов |
| Рекорды — фильтры карта / режим, список | Light | «Рекорды» |
| Настройки — ник, ключ Google и токен Mapillary (с «показать»), кеш, оформление | Light | «Настройки» |
