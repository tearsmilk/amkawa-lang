# θ Тета — локальный GeoGuessr

Настольная игра «угадай, где ты»: панорама или фотография места, метка на карте мира, очки за точность.
Всё локально (рекорды в `~/Library/Application Support/Theta`), сеть нужна только для панорам и тайлов карты.
macOS 11+ Intel (Apple Silicon — через Rosetta), PySide6, тот же стиль, что у других приложений репозитория.

## Источники панорам

| Источник | Что это | Ключ | Движение |
|---|---|---|---|
| **Google Street View** (по умолчанию, если есть ключ) | настоящие интерактивные панорамы в окне QtWebEngine (Maps JavaScript API) | свой ключ Google Maps Platform, см. ниже | да, как в Google Maps |
| Mapillary | панорамы 360° и фото улиц, CC BY-SA 4.0 | бесплатный client token: mapillary.com → Developers → Register application | да, по последовательности снимков |
| Wikimedia Commons | геопривязанные фотографии мест | не нужен | нет |

**Ключ Google.** console.cloud.google.com → API и сервисы → Учётные данные → ключ API; включите **Maps JavaScript API**
и **Street View Static API**. Поиск точки идёт через бесплатный Street View Metadata API (`/streetview/metadata`,
`status == OK` даёт `pano_id`); платный только показ панорамы в JS API — ≈ $14 за 1000 загрузок, то есть
бесплатного кредита $200 в месяц хватает примерно на 14 000 раундов. Опция «Только официальные панорамы Google»
отбрасывает пользовательские (`copyright` без «Google»). Python ↔ страница общаются через `QWebChannel`
(`theta/sources/streetview.py`: `make_panel()`); «Без движения» выключает `linksControl`/`clickToGo`,
«Без поворота» возвращает `pov` на место, «Без зума» — `scrollwheel`/`zoomControl`, «Вернуться в начало» — `setPano(start)`.

Условия использования: тайлы OpenStreetMap запрашиваются с описательным User-Agent и кешируются на диске
(`cache/tiles`, политика tile.openstreetmap.org), под картой подпись «© OpenStreetMap»; для Commons на экране
показывается автор и лицензия; для Mapillary — «Mapillary · CC BY-SA 4.0»; Google — «© Google» (панорамы показываются
только через официальный JS API, без скачивания).

## Игра
- Карты: Мир, Европа, Россия, США, Азия, Южная и Северная Америка, Африка, Океания и любая из 177 стран
  (`assets/countries.json` — Natural Earth 110m, координаты округлены до 0,01°; случайная точка берётся только на суше).
- Режимы: **Классика** — 5 раундов, 0–5000 за раунд по формуле `5000·exp(−d / (диагональ карты · 0,1))`;
  **Страны подряд** — угадайте страну (список с поиском, проверка по полигонам офлайн), серия до первой ошибки;
  **Задание дня** — seed = дата, у всех одни и те же места, результат за день запоминается.
- Опции: время на раунд (нет / 30 / 60 / 120 с), «Без движения», «Без поворота», «Без зума».
- Пока идёт раунд, следующее место ищется в фоне.

## Управление
Мышь — осмотреться (панорама) / двигать (фото и карта), колесо — зум, стрелки — поворот.
Карта в правом нижнем углу разворачивается при наведении; **1–4** — размер, кнопка-булавка закрепляет её.
**Пробел** — ответить (и «следующий» после результата), **N** — следующий раунд, **R** — вернуться в начало,
**Esc** — выйти на главную, ⌘1 главная, ⌘2 рекорды, ⌘, настройки, ⌘\ панель.

## Запуск и сборка
```bash
cd theta && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt && .venv/bin/python run.py
python run.py --selftest          # офлайн-проверки на фейковых серверах (CI)
packaging/build_macos.sh          # Theta.app + dmg (macOS, python.org Python 3.11)
```
Сборка: `.github/workflows/theta-macos.yml` (push в `theta/**`, тег `theta-v*` или ручной запуск с `release_version`).
Образ большой — внутри QtWebEngine (Chromium) для Street View.
