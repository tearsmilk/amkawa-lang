# Figma: Мю — UI

Файл «Мю — UI» в команде **Lotus** (создаётся при первом запуске скриптов; если лимит Figma не даёт — при первой возможности).

> **Правило:** UI-кит и *все* экраны Мю живут в Figma. Любой новый экран, диалог или компонент добавляется
> в эти скрипты в том же изменении, что и код, и выкладывается в Figma.

1. `01_ui_kit.js` — страница **UI Kit**: токены (коллекции «Mu — Light» / «Mu — Dark», зеркало `mu/theme.py`),
   иконка μ, компоненты: Tool button, Workspace tab, Action card, Part row (слой / сетка / вращение),
   Parameter row (ползунок с ключами ◆), Warp grid, Rotation handle, Cut selection, Pose tile, Emotion row, кнопки.
2. `02_screens.js` — страница **Screens**:

| Экран | Темы | В приложении |
|---|---|---|
| Home — «Что оживим сегодня?», действия, недавние | Light, Dark | стартовый экран |
| Нарезка — инструменты выделения, выделение на слое, вырезать / копировать в новый слой | Light | «Нарезка» |
| Риг — дерево частей, деформер-сетка, строка активного параметра, инспектор, параметры с ключами | Light, Dark | «Риг» |
| Физика — проверка, группы, входы | Light | «Физика» |
| Студия — сцены, фото-фон, позы с превью, параметры копии | Light | «Студия» |
| Эфир — хромакей, движение, микрофон, эмоции, окно для OBS | Light | «Эфир» |
| Гайдбук — главы и текст | Light | «Гайдбук» |
