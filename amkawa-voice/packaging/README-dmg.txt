Amkawa Voice — аниме-голос в реальном времени для macOS 11+ (Intel)

УСТАНОВКА
1. Перетащите «Amkawa Voice» в папку «Программы» (Applications).
2. Первый запуск: правый клик по приложению → «Открыть» → «Открыть»
   (приложение не подписано сертификатом Apple, поэтому macOS спрашивает).
3. Разрешите доступ к микрофону, когда macOS спросит.
   Если случайно запретили: Системные настройки → Защита и безопасность →
   Конфиденциальность → Микрофон → включите Amkawa Voice.

DISCORD
1. В приложении: карточка «Discord» → «Установить виртуальный микрофон» (введите пароль).
2. «Вывод в Discord» → «Amkawa Voice Mic».
3. Discord → Настройки → Голос и видео → Устройство ввода → «Amkawa Voice Mic».
   Там же выключите «Шумоподавление» и «Эхоподавление».
4. Нажмите «Включить голос». Чтобы слышать себя — выберите «Наушники» и «Слушать себя»
   (используйте наушники, иначе будет эхо).

ГОЛОСА
- 8 встроенных голосов работают сразу, без интернета, с маленькой задержкой.
- Можно добавить любые RVC v1/v2 модели (.pth/.zip или ссылка на Hugging Face):
  «＋ Добавить RVC-модель». При первом использовании скачается ContentVec (~380 МБ).
  На Intel-процессоре RVC даёт задержку ~0.6–1 секунды.

УДАЛЕНИЕ
- В приложении «Удалить виртуальный микрофон», затем удалите приложение.
- Данные и модели: ~/Library/Application Support/AmkawaVoice

Лицензии: виртуальный микрофон основан на BlackHole (GPL-3.0, github.com/ExistentialAudio/BlackHole),
нейросетевая часть — на RVC (MIT).
