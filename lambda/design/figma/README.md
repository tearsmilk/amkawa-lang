# Figma: Лямбда — UI

Файл «Лямбда — UI» в команде **Lotus** (создаётся при первом запуске скриптов; если лимит Figma не даёт — при первой возможности).

> **Правило:** UI-кит и *все* экраны Лямбды живут в Figma. Любой новый экран, диалог или компонент добавляется
> в эти скрипты в том же изменении, что и код, и выкладывается в Figma.

1. `01_ui_kit.js` — страница **UI Kit**: токены (коллекции «Lambda — Light» / «Lambda — Dark», зеркало `lyambda/theme.py`),
   иконка λ, компоненты: Tool button, Kind card, Layer row, Number field, Paint row, Selection, Sticky (3 цвета),
   Shape with text, Connector, Board toolbar, Slide thumbnail, Site block, Button.
2. `02_screens.js` — страница **Screens**:

| Экран | Темы | В приложении |
|---|---|---|
| Home — «Что создадим?», шаблоны, недавние | Light, Dark | вкладка «Главная» |
| Design — инструменты, страницы и слои, холст с фреймами, инспектор (фрейм, автолейаут, заливка, экспорт) | Light, Dark | «Дизайн» |
| Board — доска с точками, секции, стикеры, плавающая панель инструментов | Light | «Доска» |
| Slides — миниатюры, слайд, заметки докладчика, темы | Light, Dark | «Презентация» |
| Site — брейкпоинты, страницы и секции, страница сайта, ссылка и наведение | Light, Dark | «Сайт» |
