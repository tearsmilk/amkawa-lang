# Figma: Гамма — UI

Файл «Гамма — UI» в команде **Lotus** (создаётся при первом запуске скриптов; если лимит Figma не даёт — при первой возможности).

> **Правило:** UI-кит и *все* экраны Гаммы живут в Figma. Любой новый экран, диалог или компонент добавляется
> в эти скрипты в том же изменении, что и код, и выкладывается в Figma.

1. `01_ui_kit.js` — страница **UI Kit**: токены (коллекции «Gamma — Light» / «Gamma — Dark», зеркало `gamma/theme.py`),
   иконка γ, компоненты: Action card, переключатель звука, блок «Откат», поле горячей клавиши, панель выделения,
   плашка размера и лупа, панель записи, рамка записи, обратный отсчёт, уведомление, кнопки.
2. `02_screens.js` — страница **Screens**:

| Экран | Темы | В приложении |
|---|---|---|
| Главная — действия, звук, откат, недавние | Light, Dark | главное окно |
| Настройки — сохранение, видео, звук, откат | Light | «Настройки» |
| Горячие клавиши | Light | «Горячие клавиши» |
| Выделение области для записи — затемнение, ручки, размер, панель звука | — | ⇧⌘8 |
| Запись идёт — рамка, панель с таймером, значок в строке меню, уведомление отката | — | во время записи |
