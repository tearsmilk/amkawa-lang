ν Ню — редактор кода (macOS 11+, Intel)

УСТАНОВКА
1. Перетащите «Nu» (Ню) в «Программы».
2. Первый запуск: правый клик → «Открыть» → «Открыть» (приложение не подписано сертификатом Apple).
   Если не открывается: Терминал → xattr -cr "/Applications/Nu.app"
3. Git (панель «Система контроля версий»): если git не установлен, выполните в терминале
   xcode-select --install

С ЧЕГО НАЧАТЬ
- ⌘O — открыть папку проекта, ⌥⌘O — открыть файл. Можно перетащить папку на иконку в Dock.
- Слева: Проводник, Поиск по файлам, Git. Снизу слева: ▷ запустить файл, терминал, настройки.

ГОРЯЧИЕ КЛАВИШИ (как в VS Code)
⌘P перейти к файлу · ⇧⌘P палитра команд · ⇧⌘O символы файла · ⌃G строка
⇧⌘F поиск по файлам · ⌘F найти · ⌥⌘F заменить · ⌘B боковая панель · ⌘J панель
⌃` терминал · ⌃⇧` новый терминал · F5 запустить файл · ⇧F5 остановить
⌘/ комментарий · ⇧⌥A блочный комментарий · ⌘] / ⌘[ отступ · ⌥↑/⌥↓ переместить строку
⇧⌥↑/⇧⌥↓ копировать строку · ⇧⌘K удалить строку · ⌘L выделить строку · ⌘↩ строка ниже
⌘\ разделить редактор · ⌥Z перенос строк · ⌘+ / ⌘− размер шрифта · ⌘S / ⌥⌘S сохранить (всё)

РЕДАКТОР
- Подсветка ~500 языков (Python, JS/TS, HTML/CSS, C/C++, C#, Java, Kotlin, Go, Rust, Swift, PHP, Ruby,
  SQL, Shell, Lua, Dart, Haskell, Elixir, YAML, JSON, Markdown, Dockerfile…). Язык — по расширению,
  сменить можно в строке состояния справа.
- Номера строк, направляющие отступов, подсветка пары скобок и других вхождений слова,
  автоотступ, автозакрытие скобок и кавычек, автодополнение слов из файла.
- Кодировка (UTF-8, Windows-1251…), LF/CRLF и отступы — в строке состояния.
- Файл изменён другой программой — Ню подхватит изменения сам.

ТЕРМИНАЛ
- Настоящий терминал (zsh / bash) в папке проекта, несколько вкладок, цвета, история прокрутки.
- ⌘C / ⌘V — копировать / вставить, ⌃C — прервать программу.
- F5 запускает текущий файл: python3, node, go run, swift, ruby, php, bash, gcc/clang и др.
  (нужные программы должны быть установлены).

РАСШИРЕНИЯ
- Пока без расширений — всё нужное встроено.
