# Figma: Альфа — UI

Файл «Альфа — UI» в команде **Lotus** (создаётся при первом запуске скриптов; если лимит Figma не даёт — при первой возможности).

> **Правило:** UI-кит и *все* экраны Альфы живут в Figma. Любой новый экран, диалог или компонент добавляется
> в эти скрипты в том же изменении, что и код, и выкладывается в Figma.

1. `01_ui_kit.js` — страница **UI Kit**: токены (коллекции «Alpha — Light» / «Alpha — Dark», зеркало `alpha/theme.py`),
   иконка α, компоненты: Card (обычная, с метками и участниками, просрочена, выполнена, с обложкой), List column,
   Label pills, Board tile, Composer, Popup «Метки», Rule row, Side button, Due chip, Background picker
   (картинки, свои картинки, градиенты, затемнение), Side rail (свёрнутая боковая панель).
2. `02_screens.js` — страница **Screens**:

| Экран | Темы | В приложении |
|---|---|---|
| Доски — отмеченные, все доски, шаблоны | Light | «Доски» |
| Доска — панель доски, списки, карточки, «Добавить список» | Light, Dark | доска |
| Карточка — сроки, участники, описание, чек-лист, комментарии, боковая панель | Light | щелчок по карточке |
| Автоматизация — разделы и правила | Light | «Автоматизация» |
| Редактор правила — когда / если / сделать | Light | «Создать» в автоматизации |
| Календарь | Light | вид «Календарь» |
| Дашборд | Light | вид «Дашборд» |
