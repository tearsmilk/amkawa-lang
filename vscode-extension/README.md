# Aminakawa for VSCode

Write `.amkawa`, press ▶ — it runs right inside VSCode. **No Python, nothing to install.**

## Install
Copy this folder into:
- Windows: `%USERPROFILE%\.vscode\extensions\`
- macOS / Linux: `~/.vscode/extensions/`

Restart VSCode, open any `.amkawa` file → syntax highlighting turns on.

## Run
Click the ▶ button (top-right) or press `Ctrl+F5`. A panel opens at the bottom
where the program prints output — and where you type answers if it asks (`ask`).

The whole language runs inside the extension (JavaScript). No external runtime needed.
