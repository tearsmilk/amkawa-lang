01Как запустить

Программа Aminakawa — это обычный текстовый файл с именем, оканчивающимся на .amkawa. Ты пишешь в нём строчки, а компьютер их выполняет сверху вниз.

Способ 1 — через VSCode (проще всего)

1
Установи расширение (папку из aminakawa-vscode.zip кинь в ~/.vscode/extensions/, на Windows — %USERPROFILE%\.vscode\extensions\) и перезапусти VSCode.
2
Создай новый файл, сохрани его как test.amkawa.
3
Напиши одну строчку:
nya("привет, мир")
4
Нажми кнопку ▶ справа сверху (или Ctrl+F5). Снизу откроется чёрное окно (терминал) — там будет результат.
выведетпривет, мир

Способ 2 — через терминал

Открой папку с файлом amkawa.py в терминале и напиши:

python amkawa.py test.amkawa
Если пишет, что python не найден — попробуй python3 вместо python.

02Печать — nya

nya(...) — это «показать на экране». Всё, что внутри скобок, выведется в терминал.

nya("Konnichiwa!")
nya("Меня зовут", "Хока")
nya(2 + 2)
выведетKonnichiwa! Меня зовут Хока 4

Можно выводить несколько штук через запятую — они встанут через пробел.

03Переменные

Переменная — это коробка с именем, куда можно положить значение и потом им пользоваться. Кладём через знак =.

имя = "Аои"
возраст = 17

nya(имя)
nya("возраст:", возраст)
выведетАои возраст: 17

Значение можно менять в любой момент — даже на основе старого:

счёт = 0
счёт = счёт + 10
nya(счёт)
выведет10

04Числа и математика

Считать можно как в калькуляторе:

знакчто делаетпримеррезультат

-вычесть5 - 32

/поделить7 / 23.5
%остаток от деления7 % 21
nya(10 * 5)
nya(100 / 4)
nya(10 % 3)
выведет50 25 1

05Текст (строки)

Текст всегда пишется в кавычках: "вот так". Склеивать куски текста можно плюсом:

имя = "Рин"
привет = "Привет, " + имя + "!"
nya(привет)
выведетПривет, Рин!
Число можно приклеить к тексту тоже — оно само превратится в текст: "мне " + 17 даст мне 17.

06Да / нет — hai / iie

Иногда ответ — просто «да» или «нет». В Aminakawa это hai (да) и iie (нет).

Сравнения дают «да» или «нет»:

знаксмыслпримерответ
==равно5 == 5hai
!=не равно5 != 3hai
>больше5 > 3hai
<меньше5 < 3iie
>=больше или равно5 >= 5hai
<=меньше или равно4 <= 3iie

А ещё их можно соединять: and (и), or (или), not (не).

nya(5 > 3)
nya(5 > 3 and 2 > 10)
nya(not iie)
выведетhai iie hai

07Если — moshi

Самое важное. moshi = «если». Он проверяет условие, и если оно «да» — выполняет то, что в фигурных скобках { }. Если «нет» — выполняет else (иначе).

возраст = 20

moshi возраст >= 18 {
  nya("взрослый")
} else {
  nya("ещё маленький")
}
выведетвзрослый

Несколько вариантов подряд

Если случаев больше двух — цепляй else moshi:

оценка = 4

moshi оценка == 5 {
  nya("отлично!")
} else moshi оценка == 4 {
  nya("хорошо")
} else {
  nya("бывает")
}
выведетхорошо
Правило скобок: после moshi условие всегда идёт {, а в конце блока — }. Пробелы и отступы не важны — важны именно скобки.

08Повтор — while

while = «пока». Он повторяет блок пока условие «да».

n = 1

while n <= 3 {
  nya("шаг", n)
  n = n + 1
}
выведетшаг 1 шаг 2 шаг 3
Важно! Внутри цикла что-то должно менять условие (тут n = n + 1), иначе он будет крутиться вечно и программа зависнет.

09Списки

Список — это несколько значений вместе, в квадратных скобках через запятую.

друзья = ["Аои", "Рин", "Юки"]

nya(друзья)
nya("сколько:", len(друзья))
выведет[Аои, Рин, Юки] сколько: 3

Взять один элемент

По номеру в квадратных скобках. Счёт идёт с нуля! Первый — [0], второй — [1].

друзья = ["Аои", "Рин", "Юки"]
nya(друзья[0])
nya(друзья[2])
выведетАои Юки

Добавить в список

список = [1, 2]
push(список, 3)
nya(список)
выведет[1, 2, 3]

10Перебор — for … in

Пройтись по каждому элементу списка: for имя in список { ... }. На каждом круге имя — это следующий элемент.

друзья = ["Аои", "Рин", "Юки"]

for кто in друзья {
  nya("привет,", кто)
}
выведетпривет, Аои привет, Рин привет, Юки

Перебрать числа

range(a, b) — это список чисел от a до b (не включая b).

for i in range(1, 5) {
  nya(i)
}
выведет1 2 3 4

11Функции — tyan

Функция — это кусок кода со своим именем, который можно вызывать сколько угодно раз. Создаём словом tyan. Значение отдаём наружу словом back (вернуть).

tyan поздороваться(имя) {
  back "Привет, " + имя + "!"
}

nya(поздороваться("Аои"))
nya(поздороваться("Рин"))
выведетПривет, Аои! Привет, Рин!

В скобках (имя) — это то, что функция принимает (можно несколько через запятую). Пример со счётом:

tyan сумма(a, b) {
  back a + b
}

nya(сумма(2, 3))
nya(сумма(10, 20))
выведет5 30

12Готовые функции

Эти функции уже встроены — просто пользуйся:

функциячто делает
nya(x)показать на экране
len(x)длина текста или списка
num(x)превратить текст в число
str(x)превратить в текст
ask(вопрос)спросить у пользователя, вернуть введённое
range(a, b)список чисел от a до b
push(список, x)добавить x в конец списка

Пример с вводом:

имя = ask("Как тебя зовут? ")
nya("Йо,", имя)

При запуске программа остановится и будет ждать, пока ты напечатаешь ответ в терминале.

13Discord-бот

В Aminakawa встроен свой Discord (написан с нуля). Бот умеет читать сообщения и отвечать. Вот весь бот:

# токен вставь свой
bot("ТВОЙ-ТОКЕН-БОТА")

tyan на_сообщение(text, channel, author) {
  moshi text == "!ping" {
    say(channel, "pong! nya~")
  }
  moshi text == "!привет" {
    say(channel, "Konnichiwa, " + author + "!")
  }
}

on_message(на_сообщение)
run()

Что тут что

bot("...")вставляешь токен своего бота
tyan на_сообщение(text, channel, author)что делать на каждое сообщение.
text — текст, channel — куда отвечать, author — ник написавшего
say(channel, "...")отправить сообщение в канал
on_message(...)подключить твою функцию
run()запустить бота

Добавить свою команду

Просто скопируй блок moshi и поменяй триггер и ответ:

  moshi text == "!дайс" {
    say(channel, "выпало... 6! (всегда 6, sugoi)")
  }

Что сделать до запуска

1
Зайди на discord.com/developers, создай приложение → раздел Bot → скопируй Token.
2
На той же странице Bot включи тумблер Message Content Intent — иначе бот не видит текст сообщений.
3
Пригласи бота на свой сервер (с правом писать сообщения).
4
Запусти файл как обычную программу: кнопкой ▶ или python amkawa.py bot.amkawa.
Не заработало? Скопируй красный текст ошибки из терминала и скинь мне — починю. Discord-часть я не мог проверить вживую, так что это нормально.

14Частые ошибки

Если программа выдала amkawa error: ... — не пугайся, вот что это значит:

ошибкачто значит и как чинить
unknown name 'x'используешь переменную или функцию, которую не создал. Часто — опечатка в имени.
expected '}'забыл закрыть фигурную скобку }.
expected ')'забыл закрыть круглую скобку ).
string is missing a closing quoteу текста нет второй кавычки ".
division by zeroделишь на ноль — так нельзя.
'for ... in ...' needs a list or textпосле in должен быть список (или range(...)).
function 'x' wants N argument(s)вызвал функцию с неправильным числом значений в скобках.

В каждой ошибке есть номер строки (line 5) — смотри именно туда.
