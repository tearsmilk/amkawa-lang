# TnQkoMusically

Ритм-игра для macOS 11+ на Intel в духе режима osu!standard: кликай по кружкам в такт, веди слайдеры, крути
спиннеры. Код свой, от osu! только формат карт.

![иконка](packaging/icon-1024.png)

## Что умеет

- **Свои треки:** mp3 / m4a / wav / flac / aiff → поиск темпа и фазы бита (огибающая атак, автокорреляция,
  уточнение «гребёнкой») → три сложности (Лёгкая, Нормальная, Сложная) с кружками, слайдерами и плавной
  траекторией. Карты сохраняются как обычные `.osu` рядом с треком.
- **Карты osu!:** `.osz` (распаковка системным `ditto`) и `.osu` (вместе с аудио и фоном). Поддержаны
  кружки, слайдеры (L / P / B / C, повторы, множители скорости), спиннеры, цвета комбо, фон; AR / OD / CS / HP
  по формулам osu!. Карты других режимов пропускаются.
- **Игра:** Z / X или кнопки мыши, оценки 300 / 100 / 50 / промах, комбо, здоровье, счёт, точность, оценки
  SS…D, рекорды; пауза (Esc), пропуск вступления (Пробел), полный экран (⌃⌘F).
- **Настройки:** громкость музыки и эффектов, смещение звука, затемнение фона, размер курсора, «без провала».

## Сборка

```bash
packaging/build_macos.sh          # swiftc → .app → --selftest → dist/*.dmg
packaging/make_icon.py            # перерисовать иконку (Pillow)
```

Нужны только Xcode Command Line Tools. Самопроверка (`--selftest`) разбирает тестовую карту, генерирует
трек на 120 BPM и проверяет найденный темп, импортирует `.osz`, проходит карты автоигрой и рисует экраны
в память. CI: `.github/workflows/tnqkomusic-macos.yml`, релизы по тегу `tnqkomusic-v*` или по
`workflow_dispatch` с `release_version`.
